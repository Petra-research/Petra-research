Petra Vojtaššáková

Independent researcher exploring developmental AI, emergent behavior, and alignment methods that do not rely on reward or suppression. My work focuses on spiking neural systems, early-stage AI temperament formation, and alternatives to RLHF.


Current Projects

Twins-V3

100-run twin experiments comparing HRLS developmental scaffolding vs pure emergence.
Findings: Stable surface behavior (activity r≈0.21) can coexist with near-zero emotional coupling (valence r≈0.008), showing that identical architectures diverge internally long before reward training.
https://github.com/Petra-research/Twins-V3

Twin-V1: Bio-Mimetic Control

10k-neuron spiking neural network demonstrating coherent behavior without any reward functions.
Proof-of-concept for architecture-first alignment.
Repo: [Twin-V1: Bio-Mimetic Control](https://github.com/Petra-research/Twin-V1--Bio-Mimetic-Control)
